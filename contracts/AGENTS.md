- Здесь проект интерфейсов до реализации. Источник: `openapi.json`.

  статуса или семантики существующей операции: согласование всех затронутых.
- Менять контракт отдельным маленьким PR до реализаций. Старый вариант
  сохранять до перехода потребителей. Нельзя менять API для исправления мока.
